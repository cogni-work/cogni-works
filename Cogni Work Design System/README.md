# Cogni Work — Design System

> **Firmitas · Utilitas · Venustas** — a bold, modern theme pairing electric chartreuse with deep black foundations. Inspired by Vitruvius' architectural triad: dark structural anchors (firmitas), high-contrast readability (utilitas), and vibrant lime accents (venustas).

Cogni Work is the brand behind [cogni-work.ai](https://cogni-work.ai) — the commercial home of the **insight-wave** ecosystem: 14 open-source Claude Code plugins for B2B knowledge work (consulting, sales, marketing, research, trend scouting, visual production). This design system captures the brand identity used across those deliverables and the marketing surface.

## Products represented

`cogni-work.ai` is the **services + marketplace** layer atop the open-source `insight-wave` ecosystem. Two surfaces matter for design:

1. **cogni-work.ai marketing website** — consulting-grade B2B site explaining the platform, who it's for (consulting firms, sales orgs, marketing teams), and professional services.
2. **Pitch deck / consulting deliverables** — the primary output customers see: title slide, problem framing, opportunity metrics, CTA. `raw/sample-deck.pptx` is the archetype.

A secondary surface is the **portfolio dashboard** app (HTML generated by `cogni-portfolio`), but its visual vocabulary is the same as the marketing site. UI kits in this system cover the **website** and the **deck**.

## Voice & Copy Guidelines

> The canonical reference lives in [`voice-and-copy.md`](voice-and-copy.md). The single-page browsable index is [`Voice and Copy Guidelines.html`](Voice%20and%20Copy%20Guidelines.html), and each section has a specimen card in `preview/voice-*.html` (also surfaced in the Design System tab under **Brand**).

Voice is **executive, confident, methodology-driven, quietly European**. Writing is informed by the `cogni-workspace:copywriter` skill — BLUF, Pyramid, SCQA frameworks. The full guide covers the three-register system, person & address, sentence mechanics, numbers-as-heroes, frameworks, copy-block anatomy, microcopy, do/don't rewrites, punctuation, bilingual EN/DE, vocabulary, naming, voice-across-surfaces, and a 10-second pre-ship checklist. Summary:

- **Address**: "you" to the reader, "we" for cogni-work. Never "I". Example: *"Your reps spend 2-3 days per opportunity on research and deck creation."*
- **Casing**: Sentence case for body copy; **Title Case for section headers** ("Knowledge Workers Deserve Better Tools"); `MONO UPPERCASE` short eyebrows ("THE CHALLENGE", "THE OPPORTUNITY") set in JetBrains Mono with letter-spacing.
- **Sentence length**: 15–20 words. 3–5 sentence paragraphs. Short clauses land harder.
- **Numbers are heroes**: "3.2×", "47%", "5h", "60% of their day". Always paired with a plain-language label underneath. This is the core rhythm of the deck.
- **Claims are grounded**: outputs include inline citations, quality gates; never invent statistics. Copy reflects this discipline.
- **Trilingual motto**: `Firmitas · Utilitas · Venustas` — Latin triad appears verbatim in taglines and footers.
- **Bilingual capability**: the platform supports DE/EN; German copy uses Wolf-Schneider style (short sentences, concrete verbs). The showcase JSX is in German; the website is in English.
- **No emoji**. Ever. No exclamation marks beyond the rare CTA. No em-dash-disguised filler.
- **Vibe**: *"we know what we're doing, without trying hard."* Restrained boldness — the chartreuse is loud, so everything else stays quiet.

**Copy examples from the deck:**
- *Title:* "Cogni Work — Smarter Knowledge Work"
- *Eyebrow:* "THE CHALLENGE"
- *Subhead:* "Knowledge Workers Deserve Better Tools"
- *Body:* "Professionals spend 60% of their day on low-value coordination — emails, status updates, and searching for information across siloed tools."
- *CTA:* "Ready to Work Smarter?" / "Get Started"

## Visual foundations

**Colors.** Two-tone core: `#111` near-black and `#C8E62E` chartreuse, on a warm white (`#FAFAF8`) canvas. Warm neutrals, never cool grey. Status colors are classic, saturated but not neon. The accent is **never used for body runs** — only CTAs, single-word highlights, metrics, key data, and active states.

**Type.** `DM Sans` for everything (300/400/500/600/700), `JetBrains Mono` for eyebrows, code, and numeric data in tables. Tight letter-spacing (`-0.02em` to `-0.035em`) on headings — modern, confident. Mono eyebrows are UPPERCASE with `0.12em` tracking.

**Spacing.** 4pt base. Sections breathe — 48px vertical padding inside content bands, 40px horizontal gutter on desktop. Cards: 24px interior. Generous whitespace is non-negotiable.

**Backgrounds.** No gradients. No background images on content areas. Full-bleed photography is not part of the vocabulary — the design uses **dark-light sandwich**: dark (`#111`) title/closing bands alternate with warm-white content bands to create rhythm. On hero bands, a faint 1px chartreuse vertical grid at 4% opacity creates subtle architectural texture. No repeating patterns. No hand-drawn illustrations.

**Animation.** Quiet, fast, purposeful. 150–250ms standard; `cubic-bezier(0.2, 0, 0, 1)` (deceleration) for most; linear for sliders. Fades and short color transitions only — no bounces, springs, or flourish.

**Hover states.** Primary CTA: `#C8E62E → #A8C424` (muted lime, not darker). Secondary buttons darken text or thicken border. Cards lift via selection ring (`0 0 0 3px rgba(200,230,46,0.15)`) plus a `2px` chartreuse border — not a shadow change.

**Press states.** `#8BA31E` deep lime on accent buttons; no scale transform. Dark buttons go slightly lighter (`#333`). Subtle, not theatrical.

**Borders.** `#E0E0DC` warm 1px for separators; `1.5–2px` borders on inputs (so focus states register). Selected cards use 2px chartreuse borders.

**Shadows.** Four soft steps (sm / md / lg / xl) — all warm-black at low alpha (0.04–0.14). Cards are default `sh-sm` on hover; panels use `sh-md`; modals `sh-lg`. No inner shadows. No neumorphism.

**No protection gradients, no capsules.** Overlays on dark backgrounds are solid `rgba(255,255,255,0.04)` instead.

**Layout rules.** 960px content max width for copy-heavy surfaces; 1200–1280px for dashboards. Left-aligned everything except centered heroes. Grid: 12-col with 24px gutters. Fixed top navigation (dark) on the website.

**Transparency & blur.** Sparingly. Dark-surface badges use `rgba(color, 0.15)` fills with the color as foreground. No backdrop-blur.

**Imagery.** Where photos appear, they are **neutral, high-contrast, desaturated**; never warm-tinted. In this system we have no production photography yet — see Caveats.

**Corner radii.** `8px` default (buttons, inputs); `10–12px` for cards; `6px` for small pills; `pill` for toggles/slider thumbs. Never sharp corners, never fully rounded except true pills.

**Cards.** White background, 1px `#E0E0DC` border, `12px` radius, `24px` padding, `sh-sm` shadow. Selected state swaps border for 2px chartreuse + accent-ring.

## Iconography

- **Style**: solid, filled, single-color silhouettes at 24px grid. No outlined / stroke-only icons in the core system (though the showcase uses stroked SVGs for UI affordances like arrows, checks — both styles coexist).
- **Source**: the extracted deck uses simple solid silhouettes (brain, clock, lightbulb, trending-chart, arrow). **Lucide** (via CDN) is the closest open set for the stroked UI-level icons used in the theme showcase, and is used throughout UI kits.
- **Substitution flag**: we do **not** have a proprietary Cogni Work icon font. For filled marketing icons (deck-style), we reuse the extracted PNGs in `assets/icons/deck/`. For UI-level stroked icons (menus, arrows, checks), we use **Lucide** at 2px stroke weight. *Ask: confirm this substitution or provide a branded set.*
- **Logo**: the brand mark is a simple chartreuse point-up triangle (`assets/logo/mark.svg` — also inlined as a reusable React component at `ui_kits/shared/Mark.jsx`). The wordmark renders as `cogni` + chartreuse hyphen + `work` + chartreuse `.ai` in DM Sans Bold, letter-spacing `-0.02em`.
- **Emoji**: not used.
- **Unicode symbols**: middle-dot (`·`) is used as separator in taglines (`Firmitas · Utilitas · Venustas`). Arrows (`→`) allowed inline in links/CTAs. That's it.

## Caveats & open questions

- **Fonts substituted.** The brand theme specifies DM Sans + JetBrains Mono as Google Fonts — those are the same files the production showcase uses, so this is a faithful load, not a substitution. *No action needed* unless you'd like us to bundle them locally.
- **Icon set substituted for UI surfaces.** The deck ships with a small set of solid silhouettes (brain, clock, bulb, trend, arrow) — we've copied those into `assets/icons/deck/`. For broader UI iconography (menus, arrows, checks in nav/buttons) we default to **Lucide** at 2px stroke. *Please confirm* or point us at a branded icon set.
- **No production photography.** The design discipline is typographic — we see no imagery in source materials. If marketing photography exists, drop a folder in `assets/imagery/` and we'll revise the visual foundations section.
- **Plugin UI surface is conceptual.** The plugins live inside Claude Code, which isn't branded cogni-work. The plugin UI kit is a *what it could look like* surface using the brand — treat it as a reference for dashboards, internal tools, and portfolio app screens.
- **No extended color scale.** The brand is intentionally two-tone (`#111` + `#C8E62E`) plus warm neutrals and four status colors. We did not invent a 50–900 ramp; if you need one for charts, ask and we'll derive it.
