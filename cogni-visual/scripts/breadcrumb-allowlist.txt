# Breadcrumb-guard allowlist for cogni-visual.
#
# Format: <relative-path>|<token> — one entry per line, matched on file plus
# EXACT token (deliberately not file:line, so entries survive edits that shift
# line numbers). Read by check-breadcrumbs.sh, which check-preflight.sh points
# at via BREADCRUMB_ALLOWLIST.
#
# Every entry below is a FALSE POSITIVE, not a silenced breadcrumb. The guard's
# issue-ref pattern is `#[0-9]{2,}`, which matches the leading digits of a CSS
# hex colour literal. cogni-visual is a rendering plugin, so these literals are
# load-bearing output values — scrubbing them would change what the renderers
# emit. A genuine maintainer breadcrumb must never be added here; scrub the
# prose instead.
#
# Note the token is the pattern's match, not the full colour: `#06B6D4` is
# exempted as `#06`, `#22C55E` as `#22`. Colours whose first two characters
# after `#` are not both digits (`#F59E0B`, `#8B5CF6`, `#FFFFFF`, `#F7F3EA`)
# never matched and need no entry.
#
# RETIRE THIS FILE when cogni-work/managed-service#880 lands — that issue fixes
# the pattern upstream so it stops matching hex colours, at which point every
# entry below becomes dead weight and should be deleted.
#
